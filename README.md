## Fase 1 - Definición y orientación de la situación

El proyecto utiliza el dataset Iris para definir y justificar
un problema de clasificación supervisada multiclase.

La variable objetivo corresponde a `Species`, mientras que las
variables predictoras corresponden a:

- Sepal.Length
- Sepal.Width
- Petal.Length
- Petal.Width

Durante la Fase 1 se realiza análisis exploratorio y preparación
metodológica, sin entrenar modelos de Machine Learning.
